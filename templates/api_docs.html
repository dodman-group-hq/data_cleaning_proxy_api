Dodman Group · Data Cleaning Proxy

API Integration Guide

A stateless, in-memory CSV and XLSX cleaning service. Send a file, receive cleaned rows as JSON or CSV — either streamed directly back in the response or POSTed to your webhook endpoint asynchronously.

⚑

All requests require an API key sent as a Bearer token in the Authorization header. Obtain your key from the dashboard.

Base URL

endpoint 
https://your-deployment-url.com/api/v1

Authentication

Pass your API key as a Bearer token on every request.

http header
Authorization: Bearer dk_test_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
✕

Never send your API key in a URL query string, request body, or client-side JavaScript. Treat it like a password.

Environments

Every key is scoped to exactly one environment. The environment is encoded in the key prefix and enforced server-side on every request.

PrefixEnvironmentBehaviour
dk_test_ Test Files are silently truncated to the first 20 rows. No billing. Safe for development and CI pipelines.
dk_live_ Live Full file processing, no row cap. Every request is logged to the billing ledger. Rejected unless the server is running in DODMAN_ENV=production.
sk_sandbox_test_99 Open Sandbox Public key for the interactive sandbox UI. Limited to 5 requests per day per IP. 20-row cap.
⚠

Using a dk_live_ key against a development server returns a 400 INVALID_ENVIRONMENT_KEY error. This is intentional — it prevents accidental production data from being sent to non-production infrastructure.

Rate Limits

TierLimitScope
free60 requests / hourPer API key
starter500 requests / hourPer API key
proUnlimitedPer API key
sandbox5 requests / dayPer client IP

Rate-limited requests return 429 Too Many Requests with a Retry-After: 60 header.

POST /clean

POST/api/v1/clean

Upload a CSV or XLSX file for in-memory cleaning. Returns the cleaned data directly (stream download) or, if X-Webhook-URL is provided, queues delivery and returns immediately with 202 Accepted.

Request — multipart/form-data

FieldTypeDescription
file * File The .csv or .xlsx file to clean.
config JSON string Cleaning configuration object (see Config Schema). Optional — omit to strip whitespace from all columns.
output_format "json" | "csv" Response format when no webhook URL is supplied. Defaults to "json".

Request Headers

HeaderRequiredDescription
AuthorizationYesBearer dk_test_… or Bearer dk_live_…
X-Webhook-URLNoWhen present, cleaned JSON is POSTed to this URL asynchronously and the endpoint returns 202.
X-Clean-ConfigNoCleaning config as a JSON string (overrides the config form field).
X-Output-FormatNoHeader alternative to the output_format form field.

Config Schema

Pass a JSON-encoded config object in the config form field or X-Clean-Config header.

json schema
{
  "columns": {
    "ColumnName": ["rule1", "rule2"],
    "Phone":      ["PHONE"],
    "Full Name":  ["NAME"],
    "DOB":        ["DATE"],
    "Amount":     ["strip", "to_float", "clamp:0:1000000"]
  },
  "output_format": "json"
}

Columns not listed in columns are included in the output with whitespace stripped. Columns listed with an empty rule array [] pass through unchanged.

Column Rules

Rules are applied left to right. Multiple rules can be chained on one column.

RuleInput TypeDescription
PHONEanyNormalise to Kenyan E.164 format (2547xxxxxxxx). Returns null if invalid.
NAMEstringStrip and title-case the value.
DATEstring / numberParse 10+ common date formats and Excel serial numbers → ISO 8601 (YYYY-MM-DD).
stripstringRemove leading/trailing whitespace.
lowercasestringConvert to lowercase.
uppercasestringConvert to uppercase.
title_casestringTitle-case each word.
to_intanyCast to integer. Returns null if not numeric.
to_floatanyCast to float. Returns null if not numeric.
drop_emptyanyDrop the entire row if this column is null or blank.
fill_meannumberFill null/blank cells with the column mean.
fill_mediannumberFill null/blank cells with the column median.
fill_value:XanyFill null/blank cells with the literal string X.
clamp:lo:hinumberClamp value to [lo, hi]. Either bound can be empty (clamp::1000).
regex:pattern:replacestringApply re.sub(pattern, replace, value).

Output Formats

Set output_format to "json" (default) or "csv". The response Content-Disposition header triggers a file download automatically.

FormatContent-TypeFilename
jsonapplication/jsoncleaned_file.json
csvtext/csvcleaned_file.csv

When a webhook URL is supplied, the payload is always sent as a JSON array regardless of output_format.

Error Envelope

Every error response across the API uses this exact structure. Parse error.code for programmatic handling and error.message for display to end-users.

json
{
  "error": {
    "code":       "ERROR_CODE_CONSTANT",
    "message":    "Human-readable description.",
    "request_id": "uuid-v4-per-request"
  }
}

The request_id is also sent as the X-Request-ID response header on every request (including successful ones) for log correlation.

Python Example

python · requests
import requests, json

API_KEY  = "dk_test_your_key_here"
ENDPOINT = "https://your-deployment-url.com/api/v1/clean"

config = {
    "columns": {
        "Phone":    ["PHONE"],
        "Name":     ["NAME"],
        "JoinDate": ["DATE"],
        "Amount":   ["strip", "to_float"],
    },
    "output_format": "json",
}

with open("members.csv", "rb") as f:
    resp = requests.post(
        ENDPOINT,
        headers={"Authorization": f"Bearer {API_KEY}"},
        files={"file": ("members.csv", f, "text/csv")},
        data={"config": json.dumps(config)},
    )

resp.raise_for_status()
cleaned_rows = resp.json()
print(f"Cleaned {len(cleaned_rows)} rows")

Node.js Example

javascript · fetch + form-data
import fs   from 'fs';
import FormData from 'form-data';
import fetch   from 'node-fetch';

const API_KEY  = 'dk_test_your_key_here';
const ENDPOINT = 'https://your-deployment-url.com/api/v1/clean';

const config = {
  columns: {
    Phone:    ['PHONE'],
    Name:     ['NAME'],
    JoinDate: ['DATE'],
    Amount:   ['strip', 'to_float'],
  },
  output_format: 'json',
};

const form = new FormData();
form.append('file', fs.createReadStream('members.csv'), 'members.csv');
form.append('config', JSON.stringify(config));

const res = await fetch(ENDPOINT, {
  method:  'POST',
  headers: { Authorization: `Bearer ${API_KEY}`, ...form.getHeaders() },
  body:    form,
});

if (!res.ok) {
  const err = await res.json();
  throw new Error(err.error.message);
}

const rows = await res.json();
console.log(`Cleaned ${rows.length} rows`);

cURL Example

shell
curl -X POST https://your-deployment-url.com/api/v1/clean \
  -H "Authorization: Bearer dk_test_your_key_here" \
  -F "file=@members.csv" \
  -F 'config={"columns":{"Phone":["PHONE"],"Name":["NAME"]}}' \
  -F "output_format=csv" \
  --output cleaned_file.csv

Webhook Delivery

Add the X-Webhook-URL header to any request. The endpoint immediately returns 202 Accepted and delivers the cleaned JSON array to your URL as a background task.

python · webhook mode
resp = requests.post(
    ENDPOINT,
    headers={
        "Authorization":  f"Bearer {API_KEY}",
        "X-Webhook-URL":  "https://your-server.com/hook/cleaned",
    },
    files={"file": ("data.xlsx", f, "application/vnd.openxmlformats...")},
    data={"config": json.dumps(config)},
)
assert resp.status_code == 202
# Your webhook receives POST with Content-Type: application/json
# Body: [ { "col": "value", ... }, ... ]
✓

Webhook delivery is retried once on timeout. Your endpoint should respond with a 2xx status within 30 seconds to confirm receipt.
