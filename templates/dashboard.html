Keys prefixed dk_test_. No billing charges apply.

Allow test key in production

By default, dk_test_ requests are rejected while the platform is running in production mode, so a test key can't quietly consume production rate limits or skew usage accounting. Turn this on if you intentionally want your test key to work against the live deployment — e.g. debugging against real infrastructure before issuing a live key.

This only affects dk_test_ keys. dk_live_ keys always require production — that rule has no toggle.
